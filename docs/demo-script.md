# 演示脚本 / 录制分镜

两条片子：**横版 60–90 秒**（文章内嵌、B 站/YouTube），**竖版 15 秒**（短视频平台）。

录制前统一：窗口 1280×800，隐藏右侧栏，界面语言中文，字号默认，录 60fps，鼠标移动放慢到平时的一半，每次点击后停 0.5 秒。

---

## 横版：60 秒

| 时间 | 画面 | 旁白 / 字幕 |
|---|---|---|
| 0–5s | 空输入框，光标在闪 | 「大多数提问，都是这样一句话。」 |
| 5–10s | 打字：`我最近想找一份工作，` | — |
| 10–13s | 鼠标移到输入框左下，点星芒图标 | 「点一下。」 |
| 13–17s | 面板出现「正在改写…」 | — |
| 17–27s | 改写结果出现，逐行停留 | 「它把这句话补成了对方能答的样子。」 |
| 27–33s | 高亮 `【待确认】已默认：…` | 「括号里是我替你假设的，不是要你填。」 |
| 33–38s | 点「写入输入框」，文字落进输入框 | 「写回去。」 |
| 38–50s | 发送，助手给出结构化回答 | 「答案的形状，变了。」 |
| 50–60s | 切到对比图：353 行文档 vs 10 条选型表 | 「同一件事，一句话问，得到综述；加一条判据，得到能用的东西。」 |
| 60s | 星芒图标 + 名字 | 「提问之前，先想清楚什么算答对了。」 |

**关键镜头**：17–27s 和 33–38s。这两段要一镜到底，不要剪，让观众看到「点一下 → 东西自己出来」的完整因果。

---

## 竖版：15 秒

| 时间 | 画面 | 字幕 |
|---|---|---|
| 0–3s | 输入框里那半句模糊的话 | 你每天都在这样提问 |
| 3–6s | 点星芒 | 点一下 |
| 6–10s | 改写结果铺满屏幕 | 它替你补上：场景 / 交付 / 判据 / 边界 |
| 10–13s | 写入、发送 | 一句话变成一个问题 |
| 13–15s | 图标 + 名字 | 星芒 · 提问改写 |

竖版不要旁白，只用字幕；开头 3 秒必须出现「一半模糊的话」和「点一下」的对比。

---

## 录制清单

- [ ] 关闭通知、隐藏桌面图标；
- [ ] 预置一个干净的会话（不要有调试痕迹、不要有本次对话内容）；
- [ ] 输入法切英文，避免候选框入镜；
- [ ] 先空跑一遍，确认改写耗时稳定在 1–2 秒（太快看不出「在生成」，太慢观众会走）；
- [ ] 录两条素材：一条正常速度，一条放慢 50%（剪慢动作用）；
- [ ] 单独录一段 5 秒的「改写前后」静态对照（做封面和缩略图）。
